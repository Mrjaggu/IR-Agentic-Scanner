# CPU-lightweight semantic retrieval signal for search/chat (src/search/embeddings.py).
# Not a sentence-transformer: huggingface.co is unreachable from this project's
# environment (verified 2026-09), but spaCy's model wheels are GitHub release
# assets, not HF-hosted, and github.com IS reachable -- see that module's
# docstring. Two install steps (pip alone won't fetch the model):
#   pip install -r requirements.txt

# Optional: retrieval falls back to BM25 + TF-IDF only (no crash) if this
# model isn't installed on a given machine -- see meta.retrieval.semantic.
